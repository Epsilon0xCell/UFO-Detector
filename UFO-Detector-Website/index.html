Log entry one

The confession, first

UFO-Detector is a novelty browser page that pretends to scan for UFOs and detects nothing real. Its detections are dice rolls. The files are index.html, script.js, style.css, the Node test file detector.test.mjs, and an MIT license.

Log entry two

The instrument as built

A circular radar 200 pixels across, dark ground, bright green ring, with a sweep drawn as a rotating gradient square clipped to the circle, turning once every 2 seconds. Under it a message line that reads Scanning for UFOs... while it works. The page takes GSAP 3.12.5 and Howler 2.2.4 from a public content delivery network, and two sound effects from Mixkit, an ambient loop at volume 0.2 that starts on page load and a detection sound at volume 0.5.

Log entry four

Running it, and the degraded cases

Open index.html in a browser, or serve the folder with python3 -m http.server and visit localhost port 8000. If a content delivery network is unreachable the page still loads, still scans, and still detects, only silently and without the pulse flourish: the blip is shown directly for 1200 milliseconds and hidden again. Browsers may hold the ambient sound until the first click or tap, and the code accepts that instead of retrying.

One repair, in log form: the blip was once centred with a CSS translate, which GSAP overwrote when it scaled the blip, so the dot could sit off centre while pulsing. It is now centred with negative margins of minus 5 pixels, half its size, which a transform cannot replace. That fault was suspected and logged, never actually observed on screen.

Log entry five

Tests, and the limit of what is known

Ten tests, all passing, run with node --test, loading the real script.js in Node against stubbed document, window, and timer objects. They cover the 3.5 second check and 0.5 second roll delay, a missed roll, detection with and without GSAP, ticks dropped during a detection, both sounds built and the ambient loop started when Howler is present, detection surviving a missing Howler or a sound that throws, the margin centring, and the element ids and network scripts in index.html.

The closing line of the log states the boundary plainly: the page was not run in a real browser for this pass, so the visual result and the actual audio were not observed, only the logic was verified.

The sun is gone and the watchers are drifting home along the boards. On a screen left open somewhere, the green ring keeps turning and the dice keep falling.
